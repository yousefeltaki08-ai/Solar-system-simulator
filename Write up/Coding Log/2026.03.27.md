Resources:

Princeton (N-Body case study) - https://introcs.cs.princeton.edu/python/34nbody/ - I already looked at this previously, however this time I focused on their integrations. They don't mention it specifically, however this:
![[Pasted image 20260327084558.png]]
is called  the "semi- implicit (symplectic) Euler method" and finds acceleration a = f/m then updates velocity with v = v + a * dt, a.scale(dt) representing a * dt, before doing the same for position using the new velocity instead of acceleration. Normal Euler integration would use the old velocity for updating the position, however symplectic Euler uses the new velocity instead which provides better stability for physical simulations. I will likely use this type of Euler for my simulation

Deadlock code (N-Body simulation) - https://introcs.cs.princeton.edu/python/34nbody/ -  I already looked at this video previously but I also focused on the integration methods used. ![[Pasted image 20260327085610.png]]
This is explicit Euler method, the standard one. This is as it uses v(n), the previous velocity, to update the position, not v(n+1), the new velocity. Semi implicit is slightly more complex but still fairly simple and as mentioned before is much more stable for physical simulations, therefore I will likely use it in my code.
